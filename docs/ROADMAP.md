# Roadmap to 0.1

## Scope

0.1.0 is the first packaged technical alpha: a Luau-controlled player explores a streamed coastline containing terrain, dense foliage, physics, audio and an ocean. Use a 16 x 16 km reference world with configurable residency. Each numbered checkpoint is completed only when its acceptance gate passes; SDK availability alone never completes a runtime milestone.

| **0.0.4** | **Threads and job scheduling.** Engine-owned SDL threads, synchronization primitives, enkiTS, bounded completion queues. | Tasks respect dependencies, results reach their owner, and shutdown safely handles outstanding work. Blocking reads do not occupy general CPU workers. |
| **0.0.5** | **Collections, memory, and identity.** Standard containers, selected Boost.Container utilities, frame scratch allocation, generation-checked handle contracts. | Capacity limits and invalidation rules are explicit. | **0.0.10** | **Diagnostics.** Dear ImGui, Tracy, CPU/GPU timings, resource counts, queue sizes, memory estimates. | Timings and resource counters respond correctly to workload changes. GPU measurements are separate from CPU submission timing. |

| **0.0.16** | **Script execution services.** Module resolution, callbacks, event delivery, memory accounting, execution deadlines, cancellation. | A broken script reports its location and traceback. Runaway script execution is interrupted. Native completions enter through the VM owner. |

## Completion and recovery

For every completed increment: update validation, commit/tag, create and verify the full local milestone ZIP, then push the branch/tag to the authorized public repository. See `BACKUPS.md`. No background automation advances milestones.

Production multiplayer replication/prediction, a full authoring editor, advanced animation/AI, virtual texturing, mesh-shader-only rendering, breaking-wave simulation and broad platform support remain beyond initial 0.1 scope unless explicitly added.
